## 1. 프로젝트 개요

### 1.1 목표
호텔 예약 데이터를 기반으로 예약 취소 여부(`is_canceled`)를 이진 분류(Binary Classification)로 예측하는 모델을 개발한다. 개발된 모델은 호텔 운영 최적화 및 수익 관리(Revenue Management)에 활용된다.

### 1.2 데이터셋
- 출처: `hotel_bookings.csv` (포르투갈 2개 호텔 대상)
- 타겟 변수: `is_canceled` (0 = 유지, 1 = 취소)
- 클래스 불균형 존재 → Accuracy 단독 평가 지표로 부적합

### 1.3 평가 지표 선택 근거
타겟 변수 분포를 확인한 결과, 유지(0)와 취소(1) 클래스 간 불균형이 존재한다.

| 지표 | 설명 |
|------|------|
| Precision | 취소 예측의 정밀도 |
| Recall | 실제 취소 건의 탐지율 |
| F1-Score | Precision / Recall 조화 평균 |
| ROC-AUC | 임계값 독립적 종합 성능 |

## 2. 데이터 전처리

### 2.1 데이터 누수(Leakage) 컬럼 제거
아래 컬럼은 타겟 변수와 인과관계가 역방향으로, 모델에 포함 시 심각한 Data Leakage가 발생한다.

| 컬럼 | 제거 이유 |
|------|----------|
| `reservation_status` | 취소 여부를 직접 반영하는 상태값 |
| `reservation_status_date` | 취소 결정일로 결과를 누출 |
| `deposit_type` | 취소와 직결된 보증금 유형 |

### 2.2 파생 변수(Feature Engineering)

| 파생 변수명 | 계산 방법 | 목적 |
|------------|----------|------|
| `room_assignment_changed` | `reserved_room_type ≠ assigned_room_type` | 방 변경 여부 |
| `total_stay_nights` | `stays_in_weekend_nights + stays_in_week_nights` | 총 숙박 일수 |
| `total_people` | `adults + children(결측 0 대치) + babies` | 총 투숙 인원 |
| `is_adr_0` | `adr == 0` 여부 (0/1) | 무료 예약(프로모션·쿠폰) 여부 |
| `Agent_check` | `agent` 컬럼 결측 여부 반전 (0/1) | 에이전트 경유 예약 여부 |
| `foreigner` | `country ≠ 'PRT'` (0/1) | 외국인 여부 |
| `arrival_date` | `year-month-day` 결합 datetime | 날짜 통합 |
| `arrival_weekday` | `arrival_date.dayofweek` | 도착 요일 |

### 2.3 상관관계 분석
`is_canceled`와 수치형 변수 간 절대 상관계수를 확인한 결과, 파생 변수들이 상위권에 다수 포진하여 피처 엔지니어링의 효과를 확인할 수 있었다.

| 순위 | 변수 | \|상관계수\| | 비고 |
|------|------|-----------|------|
| 1 | `foreigner` | 0.336 | **파생 변수** |
| 2 | `lead_time` | 0.293 | |
| 3 | `room_assignment_changed` | 0.248 | **파생 변수** |
| 4 | `total_of_special_requests` | 0.235 | |
| 5 | `required_car_parking_spaces` | 0.195 | |
| 6 | `booking_changes` | 0.144 | |
| 7 | `previous_cancellations` | 0.110 | |
| 8 | `Agent_check` | 0.102 | **파생 변수** |

> 가장 높은 상관을 보인 변수가 파생 변수 `foreigner`라는 점에서, country를 단순 인코딩하는 대신 내/외국인으로 가공한 전략이 유효했음을 알 수 있다.

### 2.4 이상치 처리
주요 수치형 컬럼의 분포를 박스플롯으로 확인하고, 컬럼 특성에 맞는 서로 다른 기준을 적용하였다.

**adr (객실 단가): 통계적 IQR 기준**

수천 달러대의 극단값이 관측되어, IQR 기준 whisker=3.0으로 극단 이상치만 제거하였다.

<p align="center">
  <img src="img/adr.png" alt="adr 박스플롯" width="420">
</p>
<p align="center"><em>그림 2. adr 박스플롯 — 5000대의 극단 이상치 존재</em></p>

**total_people (총 인원): 도메인 기준**

일반 객실 기준 10명 초과 예약은 데이터 입력 오류 또는 특이 단체 건으로 판단하여, IQR 대신 도메인 지식 기반으로 10명 초과 건을 제거하였다.

### 2.5 컬럼 제거
다음 컬럼들은 고카디널리티, 결측치 과다, 또는 파생 변수 대체를 이유로 제거하였다.

| 컬럼 | 제거 이유 |
|------|----------|
| `arrival_date_year`, `arrival_date_month` | `arrival_date`로 통합 |
| `agent`, `company` | 결측치 과다 (`agent`는 `Agent_check`로 대체) |
| `country` | 200개국 One-Hot 인코딩 시 차원 폭발 → `foreigner`로 대체 |
| `reserved_room_type`, `assigned_room_type` | `room_assignment_changed`로 대체 |

### 2.6 전처리 파이프라인 (scikit-learn Pipeline)
수치형 18개, 범주형 11개 컬럼에 대해 각각 다른 변환을 적용하는 `ColumnTransformer`를 구성하였다.

| 컬럼 유형 (개수) | 결측치 처리 | 인코딩 |
|----------------|-----------|--------|
| 수치형 (18) | 중앙값(median) 대치 | StandardScaler |
| 범주형 (11) | 최빈값(most_frequent) 대치 | OneHotEncoder (`handle_unknown='ignore'`) |

## 8. 결론 및 한계

### 8.1 주요 결론
- 데이터 누수 컬럼(`reservation_status` 등) 제거가 현실적인 예측 성능 확보에 핵심이었다.
- 파생 변수가 상관관계 상위권을 차지하며(`foreigner` 1위, `room_assignment_changed` 3위, `Agent_check` 8위) 모델 성능에 기여하였다.
- 이상치 제거 시 `adr`은 통계적 IQR, `total_people`은 도메인 기반 임계값을 각각 적용하여 컬럼 특성을 반영하였다.
- GridSearchCV 튜닝을 통해 기본 모델 대비 AUC가 추가 향상되었다.

### 8.2 한계 및 개선 방향

| 한계 | 개선 방향 |
|------|----------|
| 하이퍼파라미터 탐색 공간 제한적 | RandomizedSearchCV 또는 Optuna 도입 |
| 클래스 불균형 미처리 | SMOTE, `class_weight='balanced'` 추가 실험 |
| 시계열 특성 미반영 | `TimeSeriesSplit` 기반 교차검증 적용 |
| 변수 중요도 분석 부재 | SHAP 기반 Feature Importance 시각화 추가 |
